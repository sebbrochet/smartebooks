# 5. Two routes with the same beginning

In the Caro-Kann, two variations begin with the same knight move and exchange.
The links below show that shared beginning, but **Next** follows the selected
row all the way to Black's different recapture.

:::chess-game{id="chess-caro-kann-lines"}

```pgn
1. e4 c6 2. d4 d5 3. Nc3 dxe4 4. Nxe4 Bf5
(4... Nd7)
(4... Nf6 5. Nxf6+ gxf6 (5... exf6))
```

| Variation | Start here |
| --- | --- |
| Classical | :move[4... Bf5] |
| Karpov | :move[4... Nd7] |
| Bronstein-Larsen | :move[4... Nf6]{line="4... Nf6 5. Nxf6+ gxf6"} |
| Tartakower | :move[4... Nf6]{line="4... Nf6 5. Nxf6+ exf6"} |

This diagram also selects the Tartakower continuation when you tap it:

::chess-board{at="4... Nf6" line="4... Nf6 5. Nxf6+ exf6"}

::chess-moves

:::

Try both **4... Nf6** links. Each shows the same position at first. Step forward
twice: in the Bronstein-Larsen Variation, Black recaptures with the g-pawn
(**5... gxf6**); in the Tartakower Variation, Black uses the e-pawn (**5... exf6**).

Use **Previous** and **Next**, or the board's arrow keys, to explore your chosen
line. With the board focused, **Home** returns to the start without losing your
choice, and **End** takes you to the end of that line. Choose another variation
in the score to explore a different continuation. When you reopen the chapter,
you return to the position and line you were reading.
